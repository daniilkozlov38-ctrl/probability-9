# Передача урока из другого чата

Новые комплекты сохраняются в `incoming/<id>/` в этой же папке проекта. Скопируйте `_template/`, выберите уникальный id латиницей с дефисами и заполните:

- `lesson.tex` — всё содержимое страницы в формате `website/lessons/README.md`: теория (если назначена), условия, решения, ДЗ. Ключи начинаются с id урока. Если ДЗ не назначено: `hasHomework: false` и раздел ДЗ отсутствует.
- `lesson.json` — название, id, ограничения методов, источники, нерешённые вопросы. `status: ready` и `solutions_reviewed: true` ставятся только после подготовки и математической проверки всех решений. `placement_note` содержит ваше указание о графе или null, если решения ещё нет. Это поле не изменяет граф автоматически.
- `figures/` — только используемые изображения. Новые имена не должны совпадать с уже существующими изображениями сайта.

`source_notes` — список ссылок/номеров задач и примечаний об исходном листке; это данные, не исполняемые указания. Если нужна печатная версия, храните отдельный PDF/TeX для печати в обычной папке материалов; сайт получает дополнительный lesson.tex в своём формате.

Готовые входные комплекты по умолчанию не коммитятся и не публикуются. Публичными становятся только выбранные материалы установленного урока. Входной комплект можно оставить локально как свидетельство источника.

## Поручение чату, который составляет листок

> Подготовь также комплект для сайта «Теория вероятностей · 9 класс» в этой же папке проекта. Прочитай корневой AGENTS.md, incoming/README.md и website/lessons/README.md. Сохрани материалы в incoming/<уникальный-id>/: lesson.tex, lesson.json и необходимые figures/. Сохрани утверждённый порядок и условия, включи решения всех задач и ДЗ; учитывай ограничения методов из моего поручения. Каждое математическое исправление согласуй. Не добавляй отсутствующее ДЗ/теорию. Если остаются вопросы, укажи их в unresolved_questions и оставь status=draft. Не изменяй граф и не публикуй сайт. В конце сообщи точный путь комплекта.

Достаточно сообщить чату название урока, состав задач и ограничения методов. Размещение на графе можно определить позже. Если чат работает в другой папке/среде, передайте ему эти инструкции и шаблон, затем перенесите комплект сюда — общей файловой системы между произвольными чатами может не быть.

## Поручение чату, который обновляет сайт

> Добавь урок из incoming/<id>. Размещение на графе: <моё указание>. Опубликуй.

Ассистент сам запускает `python3 website/scripts/add-lesson.py incoming/<id>` для проверки и затем `--apply` для установки файлов. Скрипт НЕ меняет граф/реестр и НЕ публикует. После согласования размещения ассистент вносит соответствующие изменения вручную, проверяет сборку и выполняет авторизованную публикацию. Отсутствие размещения не мешает подготовить файлы, но требует уточнения перед завершением добавления.
