# Регулярное добавление урока

## Кто что делает

Преподаватель задаёт содержание и размещение на графе. Чат, который составляет листок, готовит incoming/<id>/ по incoming/README.md. Ассистент, которому поручено обновление сайта, сам запускает скрипт и проверки, вручную вносит согласованное размещение и выполняет авторизованную публикацию.

Граф и ссылки на предыдущую теорию автоматически не дополняются. Нынешняя проверка графа допускает один последовательный маршрут; при первом запросе отдельной компоненты её поддержку нужно реализовать отдельно, а не подменять решение пользователя.

## Единственная рабочая копия

Корень этого проекта — Git-репозиторий с origin daniilkozlov38-ctrl/probability-9. Для GitHub Desktop можно добавить существующий локальный репозиторий, выбрав эту папку. Не создавайте новую копию в site-planning/.

Перед работой проверьте `git status --short`, затем получите актуальный origin/main. При чистой рабочей копии используйте `git pull --ff-only`. Если есть чужие правки, сохраните их и сначала разберитесь с различиями. Не используйте reset --hard для синхронизации.

Обычный путь публикации: git commit нужных файлов и git push origin main. При проблеме CLI-авторизации ассистент может использовать подключённый GitHub. После публикации через коннектор: git fetch origin, затем при чистой рабочей копии git merge --ff-only origin/main. Если опубликованные через коннектор изменения ещё находятся локально как незакоммиченные, сначала убедитесь в точном совпадении каждого публикуемого файла с origin/main, затем допустим git reset --mixed origin/main: он обновляет индекс/HEAD, не меняя рабочие файлы. Это исключение для синхронизации, не способ терять пользовательские правки.

В Git находятся только сайт, инструкции, навык, шаблон входного комплекта и CI. Папки с другими учебными материалами, готовые incoming/<id>/ и site-planning/ исключены из Git. Входные комплекты не становятся публичными автоматически.

## Команды ассистента

```sh
python3 website/scripts/add-lesson.py incoming/<id>
python3 website/scripts/add-lesson.py incoming/<id> --apply
# Реестр и граф — отдельная ручная правка по указанию преподавателя.
python3 website/scripts/test-authoring.py
python3 website/scripts/test-add-lesson.py
node website/scripts/build.mjs
python3 website/scripts/verify-site.py
```

Скрипт принимает только готовый комплект, проверяет LaTeX/ключи/разборы/рисунки, отказывается перезаписывать существующий урок. --apply добавляет только .tex и новые изображения. Не меняет topics.json, не создаёт связи графа, не коммитит и не публикует.

После отправки main дождитесь завершения GitHub Actions, проверьте страницу и дайте ссылку. Не выдавайте успешный commit за успешную публикацию.

Резервная ветка до миграции всех уроков: backup/before-all-tex-migration. В website/ROLLBACK.md — восстановление. Прежние отдельные рабочие копии локально сохранены в site-planning/archives/pre-single-repository.zip; это резерв, не рабочий источник. ZIP-архивы не требуется обновлять после каждого урока.
