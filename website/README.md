**Теория вероятностей · 9 класс**

Статический сайт: карта из шести тем на всё окно, перемещение и масштабирование, режим списка и заполненные страницы конспектов.

Сборка без установки пакетов:

```sh
node scripts/build.mjs
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Открыть `http://127.0.0.1:4173/`. Готовый `dist/index.html` также можно открыть непосредственно в браузере: ссылки на страницы и ресурсы относительные и не требуют сервера.

Для сборки нужны Python 3 и Node.js. На этом компьютере Node доступен по пути `/Users/daniilkozlov/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node`.

`data/topics.json` задаёт название сайта, темы, координаты карточек, стороны подключения стрелок и последовательность переходов. Скрипт сборки проверяет, что порядок карточек и связи совпадают. Карта поддерживает перетаскивание, масштабирование колесом и кнопками, жест двумя пальцами и клавиши стрелок; `0` показывает всю карту.

Материалы находятся в `content/<идентификатор темы>/`: `theory.html`, `problems.html`, `homework.html`. После правок выполнить сборку. Для темы без ДЗ поле `hasHomework: false` исключает соответствующий раздел и пункт меню. Решения раскрываются кнопкой «Показать разбор».

Снимок исходников — `sources/overleaf/`; вручную проверенные условия ДЗ из учебников — `sources/textbook-homework.json`. Дополненные решения и доказательства находятся в `scripts/solution_content.py`.

Для полного повторения переноса выполнить `python3 scripts/complete-lessons.py`, затем обычную сборку. Этот явный импорт перезаписывает HTML в `content/`, поэтому его не следует выполнять после ручных правок HTML без необходимости. Он связывает каждое задание и каждую теорему с раскрываемым разбором; таблица к задаче 5 третьей темы включается внутрь решения.

Обычная сборка импорт не запускает и не меняет конспекты. Она проверяет, что у каждого задания и теоремы есть связанная кнопка, все разборы закрыты по умолчанию и в тексте не осталось `\centering`. Файл `data/solution-coverage.json` содержит полный перечень: 64 задания и примера, 9 теорем и пояснение об аксиомах. Всего 77 раскрываемых блоков с учётом альтернативных способов решения и отдельной кнопки для проверяемого ошибочного решения из условия последнего задания.

Проверка вычислений: `python3 scripts/verify-math.py`. Она перебирает исходы опытов, проверяет ответы точными дробями и тождества на конечных вероятностных пространствах, включая события нулевой вероятности.

Формулы отображаются локальной копией MathJax 3.2.2 (SVG); интернет для просмотра не требуется. Лицензия библиотеки — `assets/vendor/mathjax/LICENSE`.

`templates/` содержит общий каркас, главную и шаблон темы. `assets/` — оформление и поведение графа. Результат в `dist/` можно разместить на статическом хостинге; относительные ссылки поддерживают размещение в подкаталоге.

Вход пользователя, оценки, отметки о прохождении, отправка решений и синхронизация с Overleaf не реализованы.

На страницах тем есть правое оглавление разделов, подзаголовков, теорем и задач. Оно строится по текущему содержимому при сборке, подсвечивает текущий пункт и на экранах уже 1100 px сворачивается над материалами.

Подготовленная копия для GitHub Pages — `../site-planning/github-release/`: папка `public/` и `.github/workflows/pages.yml`. Репозиторий публикации: https://github.com/daniilkozlov38-ctrl/probability-9 . Локальные исходники конспектов в него не включены.

Занятие «Практика решения задач» импортируется из `sources/lessons/7_practice.tex` скриптом `scripts/add-practice-lesson.py`: шесть задач на урок и пять в ДЗ, по одному решению на задачу. Разбор о гепатите точно повторяет существующий. В решениях используются пройденные определения, формулы сложения и умножения, а в задаче о яйцах — баланс количества. Формула полной вероятности не вводится. Условие шахматной задачи сохранено; в разборе чайника отдельно указана нулевая вероятность срока ровно два года.

`scripts/prepare-theory-links.py` при сборке сохраняет внутренние якоря и создаёт в последнем занятии пять ссылок на разделы теории предыдущих тем. Копируется одна ссылка на всю теорию каждой темы (`#theory`), кнопок у отдельных утверждений нет. Заголовки и прежние якоря теорем сохраняются. Кнопка копирования работает и у задач, и у теории. Проверка всех ссылок: `python3 scripts/verify-site.py`.

Параметр связи `fromPosition` задаёт точку выхода вдоль стороны карточки (0–1); у перехода из независимости к практике он равен 0,8, чтобы входящая и исходящая стрелки не совпадали. На телефоне сохраняется выход снизу по центру. Начальная подгонка карты учитывает перекрытие плавающим меню.
