Редактирование «Практики решения задач»

Единственный источник: problem-solving-practice.tex (UTF-8).
В нём весь текст, условия, решения и ссылки на теорию. HTML этой темы генерируется; его не редактируйте. Остальные темы пока остаются в content/.

Структура: \section{Теория}, \section{Задачи}, \section{Домашнее задание}.
Каждое задание: \begin{task}\label{task-problems-5} … \end{task}, затем \begin{solution} … \end{solution}. Для ДЗ используйте task-homework-… . Метки уникальные и постоянные: не меняйте их у существующих задач, даже при перестановке. Нумерация на странице автоматическая. Для новой задачи придумайте новую метку, например task-problems-eggs-new.

Поддерживаются обычный текст, пустая строка для нового абзаца, комментарии %, \textbf{}, \textit{}, \emph{}, \underline{}, формулы $…$, $$…$$, \(…\), \[…\], enumerate с \item, definition, designation, theorem, proof. Внутри формул работают команды MathJax. Литерал процента в тексте: \%. Формулы с несколькими строками: \[\begin{aligned}…\end{aligned}\].
\previoustheory вставляет ссылки на теорию предыдущих занятий.
Это содержательная часть LaTeX, без \documentclass, преамбулы, \usepackage и \begin{document}. Произвольные пакеты не поддерживаются. При неизвестной текстовой команде сборка остановится и покажет ошибку. Новые рисунки пока согласуйте отдельно: поддержка includegraphics ограничена существующим набором рисунков.

Локально из папки проекта:
python3 website/scripts/preview.py
После сохранения .tex сайт пересобирается. Обновите страницу браузера. Остановить сервер: Ctrl+C.

Публикация: закоммитьте и отправьте изменённый файл на main в репозитории probability-9 (например, через GitHub Desktop), или исправьте lessons-файл внутри website/ прямо на GitHub и нажмите Commit changes. GitHub Actions соберёт сайт из исходников и опубликует его. Простого сохранения локального файла для изменения публичного сайта недостаточно. При ошибке сборки опубликованная версия сохранится. Статус — вкладка Actions.
