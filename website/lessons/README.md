# Редактирование уроков

Каждая тема имеет один исходник `.tex` в этой папке. В нём теория, условия, решения, доказательства, таблицы и подписи рисунков. Все темы используют один формат. HTML создаётся только в `.generated/` и `dist/`; эти файлы редактировать не нужно.

Файлы:
- random-events.tex — Случайные события и вероятность элементарных событий
- addition-of-probabilities.tex — Сложение вероятностей
- equally-likely-outcomes.tex — Равновозможные исходы и противоположные события (без ДЗ)
- conditional-probability.tex — Условная вероятность
- independent-events.tex — Независимость событий
- problem-solving-practice.tex — Практика решения задач
- conditional-probability-geometry.tex — Геометрия условной вероятности

Из корня проекта: `python3 website/scripts/preview.py`.
Откройте http://127.0.0.1:4173/ . После сохранения любого урока сайт пересобирается; обновите браузер. Остановить: Ctrl+C.

Разовая сборка: `node website/scripts/build.mjs`.
Отправьте изменения на main в репозитории probability-9 или отредактируйте нужный `.tex` на GitHub и нажмите Commit changes. GitHub Actions собирает и проверяет сайт, затем публикует website/dist. При ошибке новая версия не публикуется. Локальное сохранение не изменяет публичный сайт.

## Структура и постоянные ссылки

Разделы идут в порядке `\section{Теория}`, `\section{Задачи}`, `\section{Домашнее задание}`. Для темы без ДЗ последний раздел отсутствует.

```latex
\begin{task}[conditional-probability/problems/1]\label{task-problems-1}
\textbf{Задача 1.} Текст условия с формулой $P(A)=0{,}5$.
\end{task}

\begin{solution}[conditional-probability/problems/1]\label{solution-conditional-probability-problems-1}
Текст решения.
\[
  P(A\mid B)=\frac{P(A\cap B)}{P(B)}.
\]
\end{solution}
```

Текст и формулы меняйте свободно. Ключи в `[...]` и метки `\label{...}` у существующих блоков сохраняйте: от них зависят ссылки и связь условия с разбором. Ключ решения совпадает с ключом задачи. Для новой задачи скопируйте оба блока и задайте новые уникальные ключи и метки. Номер в `\textbf{Задача 1.}` — часть редактируемого текста; при перестановке исправьте его вручную. Любое количество решений оформляется отдельными solution с тем же ключом задачи, но разными label. Можно также поместить несколько способов под одной кнопкой, как в задаче про яйца.

Аналогично устроены `theorem` и `proof` с одинаковым ключом; примеры внутри теории — `example` и `solution`; аксиомы — `axioms` и `explanation`. `given` содержит разбор, предлагаемый ученику для проверки, и не заменяет правильное решение.

## Поддерживаемый LaTeX

- Обычный текст; пустая строка — абзац; `%` — комментарий, `\%` — знак процента.
- `\textbf{}`, `\textit{}`, `\emph{}`, `\underline{}`, `\\` для переноса строки.
- Формулы `$…$`, `$$…$$`, `\(…\)`, `\[…\]`. Внутри — синтаксис MathJax, в том числе `aligned`.
- Подзаголовки `\subsection{…}`.
- Окружения `definition`, `designation`, `enumerate` с `\item`.
- `\href{адрес}{текст ссылки}`.
- `\previoustheory` вставляет список ссылок на теорию пяти предыдущих занятий в практическом уроке.

Таблица:
```latex
\begin{tabledata}{Подпись таблицы}
Величина & 1 & 2 \\
Вероятность & $\frac14$ & $\frac34$ \\
\end{tabledata}
```

Рисунок (файл находится в `website/assets/figures/`):
```latex
\figure{opposite-events.png}{Событие и противоположное событие}{1860}{1860}
```
Последние два аргумента — исходная ширина и высота картинки; адаптивный размер задаётся общим оформлением.

Это LaTeX содержимого, без `\documentclass`, `\usepackage` и `\begin{document}`. Произвольные пакеты не поддерживаются. Неизвестная команда вне формул, повторная метка, незакрытый блок или отсутствие разбора останавливают сборку с сообщением об ошибке. HTML в исходниках не используется.

Интерактивная модель взвешенных клеток: `\interactive{conditional-geometry}`. Текст и задания редактируются в .tex, поведение модели — в assets/conditional-geometry*.js.
