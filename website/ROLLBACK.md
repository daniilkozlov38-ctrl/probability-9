# Возврат к прежней архитектуре

Перед переводом всех тем сохранена отдельная ветка:
https://github.com/daniilkozlov38-ctrl/probability-9/tree/backup/before-all-tex-migration

Зафиксированная версия: c3f1744b1594928b75f32cf121ad7c1b3e4d5b67.
Это рабочая версия, где «Практика решения задач» уже редактировалась в LaTeX, а остальные темы — в HTML.

Локальная полная копия прежних исходников и готового сайта: `site-planning/before-all-tex-migration.zip` (относительно корня проекта). Распакуйте в отдельную папку для просмотра; не смешивайте с новой версией.

Для восстановления сайта на main с сохранением всей истории можно в чистом клоне репозитория выполнить:

```sh
git fetch origin
git switch main
git pull --ff-only
git restore --source=c3f1744b1594928b75f32cf121ad7c1b3e4d5b67 --staged --worktree .
git commit -m "Restore architecture before all-TeX migration"
git push origin main
```

Перед этим сохраните текущие незакоммиченные изменения. Восстановление заменяет рабочие файлы состоянием резервной версии, но не удаляет последующую историю коммитов. Будет восстановлен и прежний сценарий GitHub Actions, затем сайт опубликуется автоматически. Резервную ветку не удаляйте и не используйте для текущего редактирования.
